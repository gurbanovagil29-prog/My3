# Нейродиктофон

Превращает запись с диктофона (30–40+ минут) в текст с подписями спикеров, а при желании — в блоки «вопрос — ответ», ТЗ или конспект.

```
аудио → ffmpeg (16 кГц моно) → faster-whisper (распознавание) → спикеры (TitaNet) → .txt / .timecodes.txt / .srt
                                                               └→ Claude по шаблону → .tz.md / .summary.md
```

Распознавание работает **локально и бесплатно** (модель Whisper large-v3-turbo), запись никуда не отправляется.

## Установка

Нужны Python 3.9+ и ffmpeg.

```bash
# ffmpeg: macOS — brew install ffmpeg; Ubuntu — sudo apt install ffmpeg; Windows — winget install ffmpeg
pip install -r requirements.txt
```

При первом запуске модели скачаются автоматически: Whisper (~1.6 ГБ) и модель голосов (~40 МБ, в `~/.cache/neuro-dictaphone/`).

## Использование

```bash
# Текст + блоки «вопрос — ответ» с таймкодами (по умолчанию)
python transcribe.py запись.m4a

# Если точно знаете число участников — разметка спикеров будет надёжнее
python transcribe.py запись.m4a --speakers 4

# Встреча записана несколькими файлами — один документ со сквозными таймкодами и спикерами
python transcribe.py часть1.m4a часть2.m4a --name встреча

# С анкетой встречи (вопросы, контроли) — ИИ исправит по ней термины и проставит номера пунктов
python transcribe.py запись.m4a --context анкета.md

# Только текст
python transcribe.py запись.m4a --structure none

# Текст + ТЗ (нужен ключ Claude API)
export ANTHROPIC_API_KEY=sk-ant-...
python transcribe.py запись.m4a --structure tz

# Текст + конспект встречи
python transcribe.py запись.m4a --structure summary
```

Без `ANTHROPIC_API_KEY` сохранится **готовый промпт** (`*.prompt-qa.md`) — его можно целиком вставить в любой чат с ИИ.

### Что получится в `output/`

| Файл | Что внутри |
|---|---|
| `запись.txt` | Текст по репликам: `Спикер 1: …` — для копирования в ИИ |
| `запись.timecodes.txt` | То же с таймкодами: `[12:34] Спикер 2: …` |
| `запись.srt` | Субтитры с метками спикеров |
| `запись.qa.md` | Блоки «[таймкод] Вопрос → Ответ», каждый вопрос отдельно (шаблон по умолчанию) |
| `запись.tz.md` / `запись.summary.md` | ТЗ или конспект (с `--structure tz` / `summary`) |

### Опции

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--model` | `large-v3-turbo` | `large-v3` — чуть точнее и в ~2 раза медленнее; `medium`/`small` — быстрее, но хуже |
| `--device` | `auto` | `cuda` для видеокарты NVIDIA, иначе `cpu` |
| `--language` | `ru` | Язык записи |
| `--out` | `output` | Папка результатов |
| `--name` | имя 1-го файла | Имя файлов результата |
| `--context` | — | Файл с вопросами/контролями/терминами встречи |
| `--speakers` | авто | Число участников, если известно |
| `--no-speakers` | — | Не размечать спикеров |
| `--structure` | `qa` | Шаблон из `prompts/`: `qa`, `tz`, `summary` или `none` |

## Спикеры

Голоса различаются автоматически: для каждого предложения считается голосовой «отпечаток» (модель TitaNet), затем похожие голоса группируются. Получаются метки «Спикер 1», «Спикер 2» и т.д., пронумерованные по первому появлению. Шаблон `qa` просит ИИ сопоставить их с именами и сторонами (аудитор / компания) по обращениям в разговоре.

Ограничения: на коротких репликах («да», «угу») и при перебивании метка может ошибаться; похожие голоса иногда сливаются в одного спикера. Если число участников известно, укажите `--speakers N`.

Распознанный текст каждого файла кэшируется в `output/.cache/`: если догрузить вторую часть и запустить снова с обоими файлами, первая часть не пересчитывается.

## Скорость

- Видеокарта NVIDIA: 40 минут записи ≈ 2–4 минуты.
- Процессор (4 ядра): примерно 0.5–1× длительности записи.

## Свои шаблоны

Положите файл `prompts/<имя>.md` с плейсхолдером `{transcript}` (сплошной текст) или `{transcript_timed}` (каждая фраза с таймкодом) — он сразу станет доступен как `--structure <имя>`.
